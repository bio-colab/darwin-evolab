# مصادر المواصفات

## TI NE555 Datasheet (SLOS095)

### الصيغ الأساسية:
- **التردد**: f = 1.44 / ((R1 + 2×R2) × C1)
- **دورة العمل**: D = (R1 + R2) / (R1 + 2×R2)
- **زمن High**: t_high = 0.693 × (R1 + R2) × C1
- **زمن Low**: t_low = 0.693 × R2 × C1

### جهود العتبة:
- **العتبة العليا**: 2/3 VCC (≈3.33V عند VCC=5V)
- **العتبة الدنيا**: 1/3 VCC (≈1.67V عند VCC=5V)

### نطاق التشغيل:
- جهد التغذية: 4.5V - 16V
- تيار الخرج: ±200mA كحد أقصى
- زمن الانتقال: <100ns

### التحقق من المحاكاة (ngspice-39):
مع R1=10k, R2=10k, C1=100n, VCC=5V:
- التردد المقاس: 480Hz (النظري: 480Hz) ✓
- دورة العمل: 66.5% (النظرية: 66.7%) ✓
- Vout_pp: 5V ✓

### تحليل تجربة الهدف (1kHz / 5V / 50% Duty Cycle):
**النتيجة**: لم تحقق الدائرة القياسية المواصفات المطلوبة.

**الأسباب**:
1. **قيد دورة العمل**: في دائرة Astable القياسية لـ NE555، دورة العمل دائماً > 50% لأن:
   - D = (R1 + R2) / (R1 + 2×R2)
   - لتحقيق 50% تماماً، يجب أن يكون R1 = 0 (غير عملي)
   
2. **التردد**: لتحقيق 1kHz مع الحفاظ على مكونات عملية:
   - يتطلب قيم R و C مختلفة عن القيم القياسية
   - لكن حتى مع الضبط، تبقى دورة العمل > 50%

**الحلول الممكنة**:
- إضافة ديود موازٍ لـ R2 لفصل مسار الشحن عن التفريغ
- استخدام دائرة Modified Astable لتحقيق Duty Cycle ≈ 50%
- تعديل الخوارزمية الجينية للبحث عن تكوينات معدلة للدائرة

**الخلاصة**: المحاكي ngspice عمل بدقة، لكن القيود الفيزيائية لدائرة NE555 القياسية تمنع تحقيق 50% Duty Cycle بدون تعديلات إضافية.
