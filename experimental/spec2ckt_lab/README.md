# spec2ckt_lab (Historical Prototype)

> **Historical Status: Archived / Deprecated**

This directory contains an early exploratory prototype (`spec2ckt_lab`) developed during initial research into specification-conditioned analog circuit synthesis.

### Provenance & Evolution:
- The concepts, PDK models, and grammar guards explored here have been fully graduated and consolidated into:
  1. `src/evolab/silicon/` (Official analog CMOS PDK modeling, OpAmp sizing, and grammar guards).
  2. `experimental/electronics/` (Full modular circuit workbench, CGP bridges, and multi-corner SPICE evaluation).
- This directory is preserved strictly for academic provenance, auditability, and historical benchmark continuity. It is not part of the active CI test suite.
