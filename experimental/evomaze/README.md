## 1. Overview
`EvoMaze` demonstrates evolutionary search in procedural content generation:
- **MST Topological Genome**: Minimum Spanning Tree topological invariant guaranteeing 100% mathematical solvability.
- **Multi-Objective Metrics**: Explores trade-offs between path length, branching factor, dead ends, and spatial entropy.
- **Export Formats**: ANSI terminal visualization and Godot 4 / Unity JSON tilemap matrices.
